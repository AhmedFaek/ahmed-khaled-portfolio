Alt text: Flowchart of StarDewedar's authentication and RBAC lifecycle across four stages: account provisioning (Super Admin creating verified staff accounts via POST /api/auth/create-user versus public customer registration with 6-digit email verification), login issuing a 15-minute JWT access token and a 7-day refresh token stored as a bcrypt hash in PostgreSQL, protected request verification loading the live user role from the database before enforcing RBAC permissions (separating 401 Unauthorized from 403 Forbidden), and refresh token rotation that invalidates the previous refresh token hash on every refresh.
Caption: JWT authentication, live-database RBAC verification, and bcrypt-hashed refresh token rotation in StarDewedar.
